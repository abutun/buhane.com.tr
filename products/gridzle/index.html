Counts-first mobile puzzle game

Gridzle

For puzzle players who prefer reading numerical constraints and planning placements before acting.

Gridzle makes the counts the starting point. Row and column targets guide each placement, while every move changes the board state.

What does it do?

  • Read row and column counts before placing a piece.
  • Use a placement mechanic that toggles affected cells.
  • Progress through five tiers and 250 levels with offline-first play.

How it works

  1. 1

    Compare the visible counts with the current board.

  2. 2

    Choose a geometric placement and anticipate which cells will toggle.

  3. 3

    Check the new counts, then adjust the next placement.
