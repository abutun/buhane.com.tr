Elapsed-time reminder app

Lastimo

For people who want a calm answer to “how long has it been?” for a small set of everyday activities.

The last time an everyday activity happened can be hard to recall. Lastimo keeps one current timestamp for each of six provided presets and turns it into plain elapsed-time wording.

Open the official product site

A product built by Buhane Information Technologies. Meet Buhane.

What does it do?

  • Use six provided activity presets: haircut, oil change, dentist, intimacy, gym, and doctor.
  • Set the current moment with the Log now action.
  • Hide a preset, restore it, or delete its saved data.

How it works

  1. 1

    Choose one of the six provided presets.

  2. 2

    Tap Log now when the activity happens in the present moment.

  3. 3

    Return later to read the plain elapsed-time answer.

Data and safety context

Use it deliberately

The six presets can reflect personal routines. Enter only the present timestamp you intend to keep and use the available hide, restore, or delete controls when needed.

Important boundary

What is it not?

Lastimo keeps one current last timestamp for each provided preset. It is deliberately limited to those six choices and present-moment entry.

Buhane's builder perspective

Why this product?

Buhane designed Lastimo around one direct question and a calm answer, keeping the interaction intentionally smaller than a general-purpose life-record system.
